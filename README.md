Frontend-only label printing for the **Niimbot B1**. No Niimbot app, no backend.
Talks to the printer from the browser over **Web Bluetooth** or **Web Serial (USB)** using the
unofficial [`@mmote/niimbluelib`](https://github.com/MultiMote/niimbluelib) protocol library.

- **Templates** – paste monochrome HTML (e.g. generated by a local agent). `{{fields}}` become a form.
- **Designer** – drag & drop text, Lucide icons, QR, barcodes, shapes, images. Output is the same HTML template format, so you can promote a design to a reusable template ("Use as template →").
- **Batch** – paste CSV, one label per row.
- Everything you see in the preview is the exact 1-bit bitmap that gets sent to the printer.

## Run

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # static site in dist/ — host anywhere over HTTPS
```

Use **Chrome / Edge** (desktop or Android). Web Bluetooth and Web Serial need HTTPS or `localhost`.
Safari and Firefox have neither API. Close the Niimbot app first — the printer accepts one connection.

## Template format

1 CSS px = 1 printer dot (203 dpi → 8 dots/mm). B1 print head is 384 dots (48 mm) wide.
50×30 mm → 384×240, 40×30 → 320×240, 40×20 → 320×160, 30×15 → 240×120.

| Feature | Syntax |
|---|---|
| Parameter | `{{name}}` or `{{name\|default}}` (values are HTML-escaped) |
| Conditional | `data-if="name"` – element removed when value is empty / `0` / `false` |
| Auto-fit text | `data-fit` on a div with explicit width + height (optional `data-fit-min` / `data-fit-max`) |
| QR code | `<qr value="{{url}}" size="100" ecc="M" margin="0"></qr>` |
| Barcode | `<barcode value="{{sku}}" format="CODE128" height="60" module="2" fontsize="16" text="true"></barcode>` |
| Icon | `<icon name="flame" size="48" stroke="2"></icon>` – any [Lucide](https://lucide.dev/icons) name |
| Metadata | `<script type="application/nimprint+json">{"name","size":{"width","height"},"params":{…}}</script>` |

Param metadata: `label`, `type` (`text` · `textarea` · `number` · `select` + `options` · `checkbox`), `default`.

Rules of thumb: black on white only, no external resources (use system fonts, `data:` URIs for images),
position with `position:absolute`, keep text ≥ 20 px and bold for small sizes, lines ≥ 2 px.
The **Copy agent prompt** button copies a ready-made instruction block to hand to an LLM agent.

The page is rasterised through an SVG `<foreignObject>`, then thresholded (or Floyd–Steinberg dithered) to 1-bit.

## Layout

```
src/printer.ts   connection + print job (niimbluelib)
src/render.ts    template HTML → 1-bit canvas
src/template.ts  params, placeholders, CSV
src/designer.ts  drag & drop editor, model → HTML
src/samples.ts   example templates
src/main.ts      UI
```

## Status / caveats

The rendering pipeline and UI were exercised in a browser; **printing to real B1 hardware has not been
tested** by the author of this scaffold. If a print is garbled, check density (1–5), label stock type,
and the log panel. Unofficial protocol: not affiliated with Niimbot.
